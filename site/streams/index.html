Quickstart

Point a number
at a URL.

An app is a WebSocket URL and a protocol. Create it, then point a number at it. Calls open a socket to your bot.

Terminal
$ fonoster applications:create \
--name support-bot \
--url wss://bot.acme.com/ws \
--flavor twilio # or native
✔ Application created: 7f3c9a…
$ fonoster sipnet:numbers:update 2b81e4…
? Application support-bot
? Ready? Yes
