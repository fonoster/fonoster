Fonoster is an open-source platform for building, testing and running voice agents on real phone
lines. Your agent answers calls on your numbers, makes calls, transfers to people and keeps a record
of every conversation.

Use Fonoster Cloud, or run Fonoster on your own servers. Your agents and code work the same on both.

## Two ways to build

<CardGroup cols={2}>
  <Card title="Autopilot" icon="robot" href="/quickstart">
    Fonoster runs the agent for you. Write the prompt, pick the voice and the language model, and
    give it tools. You don't run a server.
  </Card>
  <Card title="Streams" icon="code" href="/concepts/how-fonoster-works">
    You run the agent on your own WebSocket server. Write it with the Voice SDK for Node.js or
    Python, or connect a Twilio or Pipecat bot you already have.
  </Card>
</CardGroup>

## What every call gets

Both ways share the same phone layer, so you don't build it yourself:

- Numbers and SIP trunks from the carrier you choose
- Transfers to a person, cold or warm
- DTMF: read and send keypad tones
- Answering-machine detection on outbound calls
- Recording, with a consent prompt when you need one
- A signed record of every call, with its transcript and recording
- Webhooks when calls start and end
