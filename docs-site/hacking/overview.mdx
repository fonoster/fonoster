This section is for people who change Fonoster itself: fix a bug, add a feature, or work on one of
its components. To build agents and voice apps on Fonoster, start at the
[Introduction](/introduction). To run it on your own servers, see
[Self-hosting](/self-hosting/overview).

You develop in the dev container, and only there. The dependencies run as containers, and the API
server, gateway, Autopilot, Roomr node and dashboard run from your source with reload. Fake speech
and AI providers stand in for the vendors, so you need no keys to make a call.
