Self-hosting means you run Fonoster on your own machines, with your own data, carriers and
dashboard. This section is for the people who install and operate it. To build agents and voice
apps, go to the **Docs** tab. To run a private region joined to a control plane, go to the
**Private regions** tab.

The install runs on one machine with Docker Compose and includes only what a call needs: the voice
path, the API and dashboard, Autopilot and storage. You add vendor keys per workspace in the
dashboard. ClickHouse metrics, telemetry and hosting private regions are optional integrations.
