`@fonoster/sdk` manages a workspace from Node.js or the browser: applications, numbers, trunks,
SIP agents, calls, call records, webhooks, providers and keys. It wraps Fonoster's
[gRPC API](/reference/api). To answer calls with your own code, use the
[Voice SDK](/reference/voice-sdk) instead.

## Install

```bash
npm install @fonoster/sdk
```

The package works in Node.js and in browsers. In the browser it talks grpc-web to the same
endpoint.

## Create a client and sign in

Create a client with your workspace's access key ID, then sign in with an API key:

```javascript
const SDK = require("@fonoster/sdk");

const client = new SDK.Client({
  accessKeyId: "WO7d2kq9x4m1c8b3n6p0r5t2v9y4z7a1e3"
});

await client.loginWithApiKey(
  process.env.FONOSTER_API_KEY, // APk3n8q2w7e5r1t9y4u6i0o3p8a2s5d7f1
  process.env.FONOSTER_API_SECRET
);

const apps = new SDK.Applications(client);
```

The client's `accessKeyId` selects the workspace: every request goes to the workspace whose access
key ID starts with `WO`. The API key ID (`AP…`) and its secret prove who you are. See
[API keys and access](/workspace/access) for where to find each value.

### `Client` options (Node.js)

<ParamField path="accessKeyId" type="string" required>
  The workspace's access key ID (`WO` and 32 characters). Every request acts on
  this workspace.
</ParamField>
<ParamField path="endpoint" type="string" default="api.fonoster.ai">
  The gRPC endpoint, as `host` or `host:port`. Set it to your install's address
  when you self-host.
</ParamField>
<ParamField path="caFile" type="string" default="FONOSTER_CA_FILE">
  A PEM file of certificate authorities to trust besides your system's, such as
  an install's generated `config/tls/ca.pem`. Used for gRPC and the HTTP routes.
  Host names are still checked. A missing file fails when the client is created.
</ParamField>
<ParamField path="allowInsecure" type="boolean" default="false">
  Connect without TLS. Only for plain connections inside a private network, such
  as one service calling another. To reach an install over HTTPS with its
  generated certificate, use `caFile`.
</ParamField>
<ParamField path="httpUrl" type="string">
  The base URL of the HTTP routes (call records and regions). Default `https://`
  plus the endpoint's host, without the port.
</ParamField>
<ParamField path="withoutInterceptors" type="boolean" default="false">
  Turn off automatic token renewal.
</ParamField>

### `WebClient` options (browser)

The browser build exports `WebClient` instead of `Client`. It takes `url` (default
`https://api.fonoster.ai`) and `accessKeyId`, and has the same sign-in methods.

### Sign-in and session methods

These are methods of `Client` and `WebClient`. Each sign-in method stores the tokens on the client;
the client renews the access token before a request when it has expired.

| Method                                                                      | Purpose                                                                                                                      |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `loginWithApiKey(accessKeyId, accessKeySecret)`                             | Sign in with an API key. The usual choice for code                                                                           |
| `login(username, password, twoFactorCode?)`                                 | Sign in as a user with email and password                                                                                    |
| `loginWithRefreshToken(refreshToken)`                                       | Sign in with a refresh token you kept                                                                                        |
| `loginWithVerificationCode(email, code)`                                    | Sign in with the 6-digit code from `sendVerificationCode("EMAIL", email)`                                                    |
| `loginWithOauth2Code("GITHUB", code)`                                       | Sign in with a GitHub OAuth code                                                                                             |
| `logout()`                                                                  | Forget the tokens and revoke the refresh token                                                                               |
| `refreshToken()`                                                            | Renew the access token now                                                                                                   |
| `setAccessKeyId(accessKeyId)`                                               | Switch to another workspace you belong to                                                                                    |
| `getAccessKeyId()`, `getAccessToken()`, `getRefreshToken()`, `getIdToken()` | Read the current values                                                                                                      |
| `getCapabilities()`                                                         | What the deployment supports: sign-in methods, sign-up policy, billing, regions and SIP connection details. Needs no sign-in |

## Conventions

- Every method returns a promise. A rejected gRPC call rejects with the gRPC error.
- **Refs** are UUIDs, such as `3f8b2c71-9d4e-4a6b-8c25-7e1f0a9b4d62`. `create*`, `update*` and
  `delete*` methods resolve to `{ ref }` unless noted.
- **List methods** take `{ pageSize, pageToken }` and resolve to `{ items, nextPageToken }`. Pass
  `nextPageToken` back as `pageToken` to get the next page.
- **Dates** are `Date` objects unless noted.
- `CallRecords` and `Regions` use HTTP. They reject with `CallRecordsError` or `RegionsError`,
  which carry `status` (the HTTP status) and `code` (the error code from the body).

## Applications

An application is a stream (`STREAM`) or an Autopilot agent (`AUTOPILOT`).
`new SDK.Applications(client)`.

| Method                                               | Purpose                                                                                                                                             | Returns                                                                                                               |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `createApplication(request)`                         | Create a stream or an agent                                                                                                                         | `{ ref, signingSecret, signingSecretHint }`. The secret is shown only here and on rotation; Autopilot agents get none |
| `getApplication(ref)`                                | Get one application                                                                                                                                 | `Application`                                                                                                         |
| `updateApplication({ ref, ...fields })`              | Replace the application; fields you leave out reset to their defaults. Read it with `getApplication`, change what you need, and send all of it back | `{ ref }`, plus `signingSecret` when the update generated a new one                                                   |
| `listApplications({ pageSize, pageToken })`          | List applications                                                                                                                                   | `{ items: Application[], nextPageToken }`                                                                             |
| `deleteApplication(ref)`                             | Delete an application                                                                                                                               | `{ ref }`                                                                                                             |
| `rotateSigningSecret(ref)`                           | Replace a stream's signing secret                                                                                                                   | `{ ref, signingSecret, signingSecretHint }`                                                                           |
| `evaluateIntelligence({ intelligence: { config } })` | Run an agent's test cases                                                                                                                           | An async iterator of events: `stepResult`, `scenarioSummary`, `evalError`                                             |
| `createTestToken()`                                  | Get a short-lived token for a test call from the browser                                                                                            | `{ domain, displayName, signalingServer, targetAor, username, token }`                                                |

An `Application` has the same fields, plus `ref`, `signingSecretHint` (the secret's last
characters), `createdAt` and `updatedAt`.

| `getNumber(ref)`                       | Get one number                                                                                                                                                                                                |                                                                                                                                                                                                                            | `{ ref, name, telUrl, appRef, agentAor, city, country, countryIsoCode, trunk: { ref, name }, createdAt, updatedAt }` |
| `updateNumber({ ref, ...fields })`     | Change the name, trunk or destination                                                                                                                                                                         | `name`, `trunkRef`, `appRef`, `agentAor`                                                                                                                                                                                   | `{ ref }`                                                                                                            |
| `listNumbers({ pageSize, pageToken })` | List numbers                                                                                                                                                                                                  |                                                                                                                                                                                                                            | `{ items, nextPageToken }`                                                                                           |
| `deleteNumber(ref)`                    | Remove a number                                                                                                                                                                                               |                                                                                                                                                                                                                            | `{ ref }`                                                                                                            |

Linking it again updates it in place                                                       | `phoneNumber` (`+18095550123`), `name` (defaults to `phoneNumber`), one destination: `appRef` or `agentAor`, and `credentials`: `accountSid` with `apiKeySid` and `apiKeySecret` (a Standard API key), or with `authToken` | `{ ref, trunkRef }`                                                                                                  |

## Calls

Start outbound calls and read call history. `new SDK.Calls(client)`.

| Method                | Purpose                                        | Key params                                                                                | Returns                    |
| --------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------- | -------------------------- |
| `createCall(request)` | Dial a number and connect it to an application | `from`, `to`, `appRef` (required), `timeout` (seconds, default 30, up to 120), `metadata` | `{ ref, statusStream }`    |
| `getCall(ref)`        | Get one call                                   |                                                                                           | `CallDetailRecord`         |
| `listCalls(request)`  | List calls                                     | `after`, `before`, `type`, `status`, `from`, `to`, `appRef`, `pageSize`, `pageToken`      | `{ items, nextPageToken }` |

`statusStream` is an async iterator of `{ status }` while the call is dialed. `status` is one of
`TRYING`, `PROGRESS`, `ANSWER`, `BUSY`, `CANCEL`, `FAILED` or `ERROR` (no answer).
`metadata` reaches the application in `session.start`.

A `CallDetailRecord` has `ref`, `accessKeyId`, `status`, `type` (`SIP_ORIGINATED`,
`API_ORIGINATED`), `from`, `to`, `duration`, `direction` (`FROM_PSTN`, `TO_PSTN`,
`INTRA_NETWORK`), `startedAt`, `endedAt` and `appRef` (the app that handled the call; absent when
none did). When answering-machine detection ran, it also has
`amdStatus`, `amdConfidence`, `amdDetector`, `amdLatencyMs` and `amdCause`.

## Usage

What the workspace consumed, in quantities, never money. `new SDK.Usage(client)`.

| Method              | Purpose                                                           | Key params                                                                                                                                                           | Returns                |
| ------------------- | ----------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------- |
| `getUsage(request)` | Usage totals for a range of days (UTC, inclusive), split by meter | `fromDay`, `toDay` (`YYYY-MM-DD`), `groupBy` (any of `day`, `workspace`, `provider`, `model`, `key_source`, `origin`), `allOwned` (owners: every workspace they own) | `{ rows: UsageRow[] }` |

A `UsageRow` has `meter`, `unit` and `quantity`, plus the dimensions you grouped by. Meters:
`call.seconds` (from answer to hangup), `stt.seconds`, `tts.characters`, `llm.tokens.in`,
`llm.tokens.out`, `llm.tokens.cached`, `embedding.tokens`, `nc.seconds` (noise cancelling),
`amd.detections`, `amd.seconds`, `recording.seconds` and `storage.bytes` (the peak in the range,
or the day's reading when grouped by `day`). `keySource` says whether a vendor was called with your
own key (`workspace`) or the platform's (`platform`); `origin` tells calls (`call`) from browser
tests (`browser_test`) and evals (`eval`).

```ts
const usage = new SDK.Usage(client);
const { rows } = await usage.getUsage({
  fromDay: "2026-10-01",
  toDay: "2026-10-31",
  groupBy: ["key_source"]
});
```

| `inviteUserToWorkspace(request)`                | Invite someone by email                                   | `email`, `name`, `role`                              | `{ ref }`                                                                                       |
| `resendWorkspaceMembershipInvitation(userRef)`  | Send the invitation again                                 |                                                      | `{ userRef }`                                                                                   |
| `listWorkspaceMembers({ pageSize, pageToken })` | List members                                              |                                                      | `{ items: [{ ref, userRef, name, email, role, status, createdAt, updatedAt }], nextPageToken }` |
| `removeUserFromWorkspace(userRef)`              | Remove a member                                           |                                                      | `{ userRef }`                                                                                   |
| `getRegion()`                                   | The workspace's region, its status and connection details |                                                      | `Region`                                                                                        |

The workspace selected by the client's `accessKeyId` is the one these methods act on, except
`createWorkspace` and `listWorkspaces`. `role` is `WORKSPACE_OWNER`, `WORKSPACE_ADMIN` or
`WORKSPACE_MEMBER`; `status` is `PENDING` or `ACTIVE`.
